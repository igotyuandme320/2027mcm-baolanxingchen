# 第三周学习笔记：模型表达与英文写作

本篇为整理前三周笔记时补充的方法笔记与参考示例。独立中文段落、英文改写和章节提纲练习本次跳过，以下内容用于复习。

## 本周重点

前两周先了解了论文框架，又练习了公式、图表和引用。接下来需要把这些内容连成读者能理解的说明：题目要解决什么问题，为什么选这个方法，结果回答了什么，又在什么条件下成立。

模型名称和公式只是说明的一部分。论文手还要把输入、参数、输出与题目要求对应起来，避免读者看到了计算过程，却不清楚它的用途。

## 一段模型说明要写清什么

| 要素 | 写作时需要交代的内容 |
| --- | --- |
| 问题 | 研究对象、目标，以及涉及的时间或范围。 |
| 方法与理由 | 采用什么方法，它与数据特点、题目约束有什么关系。 |
| 输入与假设 | 用到哪些数据、变量和参数，作了哪些简化。 |
| 结果与证据 | 给出关键数值或趋势，并指出对应的公式、表格或图。 |
| 适用条件 | 结论依赖什么条件，有哪些误差或局限。 |

例如，第二周的匀速运动示例用速度与时间计算距离。“10 秒走了 20 米”来自给定速度和匀速假设；若要说明现实中的运动是否符合这个模型，还需要实际观测数据。这有助于区分计算结果与模型验证。

## 中文说明与英文表达的参考示例

下面根据[第二周范文的 Summary 与 §4.1.4](https://reformship.github.io/pages/3competition/4mcm/MCM%20Outstanding/2023/C/2314151.pdf)整理参考写法，描述的是例文作者的工作。

中文可以按“目标—方法—结果”的顺序写：

> 为预测 2023 年 3 月 1 日的 Wordle 成绩报告数量，例文采用了基于 Prophet 的时间序列模型。该模型将趋势、季节性和节假日影响纳入预测。论文给出的预测区间为 10355 至 18742，具体结果见正文 Table 6。

英文参考写法：

> To estimate how many Wordle results would be reported on March 1, 2023, the authors applied Prophet with components for trend, seasonality, and holiday effects. Their reported interval spans 10,355 to 18,742 (Table 6).

这段参考说明交代了预测对象、方法、结果和证据位置。它只概括一项任务；完整摘要还需要覆盖题目的其他主要任务，并根据正文补充相应的结论。

写方法选择理由时，要依据数据特点和正文分析说明，不能仅凭模型名称就宣称方法最优。英文可以先保证主语、动作和结果明确，再调整句式。

## 把章节连成一条清楚的论证

搭提纲时，可以先给每一部分写一句“本节回答什么问题”：

| 论文部分 | 本节要回答的问题 |
| --- | --- |
| 问题重述与分析 | 题目要求完成哪些任务，准备怎样拆解？ |
| 假设、符号与数据处理 | 模型依赖哪些前提，变量如何定义，数据怎样准备？ |
| 模型建立 | 为什么选择这个方法，数学关系如何对应实际问题？ |
| 求解与结果分析 | 怎样求解，关键结果是什么，对应哪项任务？ |
| 检验与模型评价 | 如何评估误差或参数变化的影响，适用范围和局限是什么？ |
| 结论与摘要 | 哪些结果最值得保留，它们是否都有正文依据？ |

正文结果比较稳定后，再回头核对摘要中的数字、条件和结论。模型改动时，要一起检查对应的图表、结果解释和摘要，保持前后一致。

## 和队友沟通时要确认的信息

- 数据与输入：来源是什么，变量和单位是否统一，做过哪些处理。
- 模型与假设：方法为什么适合题目，哪些简化会影响结论。
- 最终输出：使用哪个版本的参数、数值和图表，各自对应哪项任务。
- 结果检验：有没有误差指标、对照结果或敏感性分析，能够支持多大范围的结论。

先把这些信息确认清楚，写作时就更容易说明“为什么这样做”和“结果意味着什么”。
