# 第一周学习笔记：论文手入门

## 本周内容

这周主要了解了建模论文的基本框架，包括摘要、问题分析、模型假设、模型建立与求解、结果分析和模型评价。现在对各部分该写什么有了初步认识，但怎么把它们连起来，还需要多看、多练。

摘要要尽量讲清楚解决了什么问题、用了什么方法、得到了什么结果。写正文时，也要说明模型为什么这样建立，以及结果能回答题目中的哪些问题。

把各部分放在一起看，可以先记住它们各自要回答的问题：

| 论文部分 | 主要回答的问题 |
| --- | --- |
| 摘要 | 解决了什么问题，用了什么方法，得到什么关键结果？ |
| 问题分析 | 题目有哪些任务，准备怎样拆分和处理？ |
| 模型假设 | 简化了哪些现实情况，为什么可以这样简化？ |
| 符号说明 | 各变量、参数的含义和单位是什么？ |
| 模型建立与求解 | 如何把问题转成数学关系，又怎样得到结果？ |
| 结果分析 | 数字和图表说明了什么，是否回答了题目的要求？ |
| 模型评价 | 模型在哪些条件下适用，有哪些优点和局限？ |

这个框架用于理解写作顺序，实际章节还要根据题目和模型调整。

## 对论文手分工的理解

作为论文手，我也得跟上队伍的建模思路。变量是什么意思、公式为什么这样用、图表能说明什么，都需要和队友确认清楚。不懂的地方及时问，避免写到后面才发现理解不一致。

## 先记住的几个注意点

- 同一个变量的符号和含义要前后一致。
- 图表要有标题，正文里也要解释它说明了什么。
- 英文先把意思表达清楚，句子不用刻意写得很复杂。

## 学习体会

这周最大的感受是，想把模型讲清楚，自己得先理解它。先把基本功练起来，再慢慢提高写作和排版的熟练度。
